# 目标与服务模型

## 一、项目目标

随着计算机和网络技术的普及，办公人群、公司、和部分学生群体在将以纸作为载体的资料转化为电子文档时，由于成像器件和扫描非线性，运动模糊，曝光不均匀等的限制，导致纸质文档的图片保存中带来的几何失真（卷曲、倾斜等），明暗不均，引入噪声等问题。

本项目将办公与科技结合，在技术上由OpenCV技术和TensorFlow技术支持，可对用户的图片文件进行图像的自动矫正，为推进办公自动化提供新的动力。我们希望达成的设计目标有：

**1）整合办公资源**

本文档图片自动矫正系统致力于减少并最大化利用人力物力以及空间资源，避免重复劳力导致的资源浪费，整合办公资源，将资源最大化利用。

**2）提高办公效率**

本文档图片自动矫正系统推动了无纸化办公，为线上办公提供助力，提高整体办公效率，同时数字化文件也为信息的安全性，便捷性提供了保障。

使用本系统时用户可以对处理后的图片进行整理。如发现图片处理的过程中矫正有误，则重新进行矫正，手动调整轮廓识别的步骤，得到正确的图片来替代掉之前矫正有误的图片。避免重新识别后再次费时费力寻找图片位置的问题。

**3）增强用户体验**

系统采用基于openCV对照片进行透视矫正和基于Tensorflow的对图片进行超分辨率处理。

用户上传单张图片或批量上传图片，并指定一个存储路径存储处理后的图片，可设置是否需要转为黑白图片。按照用户上传图片时的顺序处理图片。同时图片在透视矫正后会出现不同程度的模糊现象，或是原图本身就不够清晰，因此在进行一步基于Tensorflow的超分辨率处理，提升图片清晰度，将低分辨率的图像放大2倍或者更多，同时保留足够的细节，使放大后的图像不会过于模糊或失真。

本系统采用Saas的服务架构，在web端进行开发，下图是通信流程图。

图2-1 通信流程图

输入网址后，请求由浏览器以一种满足http协议的请求报文的形式发往服务器。请求报文中包含了要请求的页面地址，请求的文件类型等一系列信息。

传递的时候，网络设备把请求报文包装在一个满足TCP协议的数据中，通过网线传送给服务器。

服务器接受数据后，将数据解译，重新恢复成浏览器满足http协议的请求报文的形式，然后传向服务器软件。

服务软件得到请求报文后，根据请求报文的页面地址在服务器数据库中找到相应的页面，生成满足http协议的响应报文发向浏览器。响应报文包括响应报文头和请求页面的代码。

响应报文通过服务器的网络设备，包装在满足TCP协议的数据，通过网线传给客户端。

客户端网络设备将响应报文解析，传给浏览器软件，浏览器将报文解析，得到网页。

我们为项目设计了如下典型且不可或缺的功能：

**1）首页**

相关信息及使用方法的动态显示；展示系统的核心内容，包括系统教程。

**2）登录注册**

用户可以选择使用个人账户，还是公司集体账户。公司集体账户可以分部门分员工进行保存文件，同时对各级部门员工设置不同了权限管理，在保证安全性的前提下对于公司内部信息的流通提供了便捷的渠道，实现账户1拖N。

**3）个人中心**

修改个人资料；基础设置：设置修改文件夹密码，默认存储位置的选择与修改；根据客户需求决定是否默认转换为黑白图片；转换图片时滤镜的选择；好友用户列表。

**4）文件上传**

支持单张上传和批量上传；上传后用户可根据个人需求对图片进行再处理，包括：自行选择文字提取功能、调整图片顺序以及背景的置换等功能。

**5）文件管理**

包括收藏夹和最近矫正两大块。支持对图片的批量修改，包括重命名，加入收藏夹和矫正/再次矫正；可对需保密的文件设置管理密码，提高文件安全性；文件预览时可在侧边栏中了解到图片滤镜及字体信息；支持关键词检索，让系统能迅速、准确地查找到用户所需的电子文档；可将文件共享给系统内的其他用户。

**6）图片处理**

包括系统自动处理和个人手动再处理两项功能；可根据需求将拍摄好的文档图片经自动矫正之后选择文本提取和背景自定义化，将未处理的文档图片转化成规范合格且带有公司特征的商业文档。

**2.2.2图片处理技术框架**

![](media/image5.png){width="4.0993055555555555in"
height="5.113888888888889in"}图2-4 项目技术框架设计图

1、为解决成像器件角度以及非正常扫描带来的几何畸形的问题，我们采用透视矫正与水平矫正来解决。即首先通过边缘检测以及霍夫变幻找到纸张的轮廓，再通过计算找到相关坐标，最后将其进行透视变换。

2、对于卷曲问题，我们使用最小二乘法作为拟合标准进行数值矫正，并采用灰度插值来处理拟合坐标。

3、对于曝光不均的图像，我们通过双边模糊，叠加原图的方式来去除图片阴影与高亮问题。

4、对于防水层或胶印纸张等反光情况的处理，我们同样采用双边模糊，最大阈值提取轮廓灰度着色，叠加原图的方式来呈现。

5、图片在透视矫正后会出现不同程度的模糊现象，或是原图本身就不够清晰，因此在进行一步基于Tensorflow的超分辨率处理。我么使用已经训良好的vgg网络，对其再次重复训练，调整训练集，并采用小尺寸图片加快训练速度进行超分辨率处理一得到一个清晰的图像。\
6、为做到调整效果普适化，每一种图片混合的算法都是经过多次实验选择的最理想算法。

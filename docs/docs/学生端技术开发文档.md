## 1. 角色定位 & 与教师端差异

学生端是**学习型产品**：没有课程创建 / 文档上传 / 图谱编辑等管理能力，取而代之的是"被动接收 + 主动学习"——通过课程加课码进入班级，在一张**交互式图谱**上探索知识点、提问 AI、生成专属学习路径、标记掌握、积累学习进度。

### 1.1 学生端 vs 教师端功能差异

| 能力 | 学生端 | 教师端 |
|---|---|---|
| 课程来源 | 凭 course_code 加入 + 公开课程 | 自建 + 管理 |
| 图谱 | 只读 + 高亮 + 路径着色 | 可编辑、审核 |
| 文档 | 仅可下载（教师允许时） | 上传 / 解析 / 触发抽取 |
| 问答 | 随时提问 + 反馈满意度 | 查看全班问答 & 处理工单 |
| 学习进度 | 给自己打掌握、看个人进度仪表盘 | 看全班统计、薄弱点、导出 |
| 学习路径 | 核心：个性化推荐 + 前置高亮 + 最短路径可视化 | 辅助：参考用 |

### 1.2 鉴权
同教师端文档 §1.3：JWT + `role=student`，Pinia `authStore` 通用，路由守卫区别仅在于路由级 role 白名单。

## 2. 信息架构 & 路由表

整体布局：**顶部横向导航（适合学生移动端优先）** + 左侧常驻"学习仪表盘摘要卡"（当屏幕≥md 时显示），移动端折叠为抽屉。

| 路径 | 页面组件 | 功能定位 | 路由守卫 |
|---|---|---|---|
| `/login` | `views/LoginView.vue` | 登录；Tab 切换「学生登录 / 教师登录」 | 仅未登录 |
| `/register` | `views/RegisterView.vue` | 学生注册（默认 role=student） | 仅未登录 |
| `/join` | `views/JoinCourseView.vue` | 输/粘贴加课码 → 展示课程摘要 → 确认加入 → 跳课程主页 | 需登录 + role=student |
| `/courses` | `views/student/MyCoursesView.vue` | 我加入的课程卡片：名称 / 教师 / 个人掌握率 / 最近学习时间 | 学生 |
| `/courses/:courseId/home` | `views/student/CourseHomeView.vue` | 学生端首页：欢迎语 + 今日推荐 3 个知识点 + 图谱缩略 + 最近问答 | 学生 + 课程成员 |
| `/courses/:courseId/graph` | `views/student/GraphExplorerView.vue` | **核心**：AntV G6 大图 + 搜索框 + 筛选(节点类型/掌握状态/关系类型) + 详情抽屉 +「加入学习路径」按钮 | 学生 + 课程成员 |
| `/courses/:courseId/qa` | `views/student/QAView.vue` | 对话式 AI 助教；左侧消息列表，右侧引用节点小图；每条回答底部可反馈「👍有用 / 👎答非所问」 | 学生 + 课程成员 |
| `/courses/:courseId/path` | `views/student/LearningPathView.vue` | 推荐路径 Step 列表 + 路径 G6 可视化 + 可勾选"我已掌握"逐步推进 | 学生 + 课程成员 |
| `/courses/:courseId/progress` | `views/student/MyProgressView.vue` | 个人仪表盘：知识点掌握进度环形图 + 按类型条形图 + 学习日历热力图 + 最近掌握时间线 | 学生 + 课程成员 |
| `/profile` | `views/student/ProfileView.vue` | 昵称、头像、邮箱、密码修改、登录设备管理 | 所有登录用户 |

### 2.1 全局「浮窗学习路径」组件
在所有 `/courses/:courseId/*` 子页面右下角放一个 60×60 的圆形浮窗按钮（🚩），点击展开一个 320 宽的 **SlideOver**：显示当前推荐路径的前 5 步，每步可勾选"我学会了"，无需切页面即可推进。这是学生端显著提升留存的重要组件。

## 3. 页面详细设计

### 3.1 登录 / 注册
**要点**：顶部 Tab 明确选择「我是学生」「我是老师」，避免串身份；密码 8 位以上；注册默认写入 `role=student`，教师注册需要邀请码或走管理后台审核（可在 `.env` 配置开关）。  
**接口**：`POST /api/auth/login`、`POST /api/auth/register`、`GET /api/auth/me`。

### 3.2 加课 `/join`
**流程**：
1. 默认输入框（自动粘贴板填充 + 带横杠美化：`XXXX-XXXX`）；
2. 点击"查找课程" → 调 `POST /api/courses/{id}/join` 先做预览（幂等，不会真正加入），后端返回 `{course, already_member: bool}`；
3. 显示课程卡：封面、课程名、教师姓名、节点数/关系数/学生数，加课须知（"加入后教师可看到你的学习进度"）；
4. 确认加入 → 再次真正调用（或同一个 join 接口自动加 member=True）→ toast "成功加入《XX》课程"，跳课程 Home。

**接口**：`POST /api/courses/{id}/join`（学生端唯一主要使用的接口）。

### 3.3 我的课程 `/courses`
卡片栅格：课程名、教师名、封面、掌握进度条（20%、绿色）、最近学习相对时间 "3 小时前学过"、底部两个 CTA：「继续学习」→ `/graph`，「学习路径」→ `/path`。  
空状态：大号加课按钮 + "去加课" → 跳 `/join`。

**接口**：`GET /api/courses`（后端按 userId 过滤学生已加入的课程）。

### 3.4 课程首页 `/courses/:courseId/home`
「欢迎，XXX ✨」大标题 + 当前掌握率。  
下方三卡片并列：
1. **今日推荐（3）**：BFS 算法算出的"距离最近未掌握"3 个知识点卡片（标题 + 类别 Badge + 前置掌握状态 3 个小 dot），点击「开始学习」→ 跳 Graph 并高亮该节点。
2. **图谱速览**：G6 小缩略版，点击进入大图。
3. **继续上次提问**：显示上一次 QA 会话的问题摘要 + 「点我继续对话」→ 跳 `/qa` 并带入上下文。

**接口**：`GET /api/courses/{id}`、`POST /api/courses/{id}/learning-path/recommend`（limit=3）、`GET /api/courses/{id}/qa/history?limit=1`。

│                                                                                                               │
│  ┌─────────────────────────────────────────┬────────────────────────────────────────────────────┐            │
│  │                                         │                                                    │            │

│  │         - 颜色=节点类型                 │     ①详情  ②先修关系(入边)  ③后续知识(出边)        │            │
│  │         - 边框粗细=degree(核心节点加粗)  │   · 底部 CTA：「标记掌握」「加入学习路径」「问 AI」  │            │

│  │                                         │                                                    │            │
│  └─────────────────────────────────────────┴────────────────────────────────────────────────────┘            │
└───────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

#### 3.5.2 关键交互（对齐 §12.6）
- 搜索框：输入关键字（防抖 300ms）→ 命中的节点高亮 `active` 态，其他节点 0.2 dim；
- 过滤多选：节点类型多选 + 掌握状态单选（全部 / 已掌握 / 未掌握 / 推荐中）；
- 节点点击：弹出详情 Drawer，**`graph.fitCenter(id)` + 放大选中 node**；
- 节点右键：菜单包含「查看详情」「标记掌握」「从这里生成学习路径」「问 AI：这个知识点学了能解决什么？」；
- 「加入学习路径」：把该节点加入 Pinia `pathStore.selection`，右下浮窗弹出小 toast「已加入今日学习清单（3/10）」。

#### 3.5.3 节点颜色 & 状态编码（G6 `style` 里）
| 类型 | 颜色 | 掌握状态叠加 |
|---|---|---|
| 概念 | #4F7CD6 | mastered=绿色边框 #34D399，strokeWidth=3 |
| 定理 | #D97706 | 同上 |
| 公式 | #DC2626 | 同上 |
| 算法 | #059669 | 同上 |
| 实例 | #7C3AED | 同上 |
| 其他 | #64748B | 同上 |
| *推荐中节点* | 同类型颜色 + 黄色光晕 `shadowColor="#EAB308"` | - |

| 非当前过滤集合 | opacity=0.25 | - |

**接口**：`GET /api/courses/{id}/graph`、`GET /api/courses/{id}/nodes/{nid}`、`POST /api/courses/{id}/learning-path/progress`（标记掌握）、`POST /api/courses/{id}/learning-path/recommend`（从某节点生成路径）。

### 3.6 RAG 问答 `/courses/:courseId/qa`（核心页面 2）

参考 §12.4 的 6 步问答流程，前端将其渲染为 **ChatGPT 式会话**。

#### 3.6.1 页面布局
```
左侧 70vw：对话区
  ┌──────────────────────────────────────────────────┐
  │ 系统提示：你好，我是 AI 助教，所有回答基于本课程内容。 │
  │ 推荐提问：5 个 chips（"学TCP需要什么基础？", ...）   │
  │ ─── 对话气泡 ───                                  │
  │ [学生气泡]                                        │
  │ [AI 气泡]                                         │
  │   正文 Markdown                                   │
  │   --- 引用（可点击跳转图谱高亮）---                 │
  │   🔗 TCP 协议(协议)  🔗 滑动窗口(算法)  ...        │
  │   👍有用 👎答非所问  不够详细                        │
  └──────────────────────────────────────────────────┘
  底部输入框 + ↑↓ 键切换历史 + Ctrl+Enter 发送

右侧 30vw：引用子图
  最近一次回答引用到的节点 + 它们之间的关系（局部小图谱）
  + "查看完整节点详情" → 抽屉
```

#### 3.6.2 回答气泡关键 UI
- 引用节点的 chip：点击 → `graphStore` 设置 `selectedNodeId` → 如果用户同时打开 Graph Explorer 就同步，否则 QA 右侧小图谱就 setSelected。
- 底部 3 个反馈（👍/👎/不够详细）→ 点击后 POST `/qa/{qid}/feedback`，按钮变灰 + toast"谢谢反馈，教师会看到"。
- 如果后端 `used_llm=false`（LLM 不可用走关键词兜底），在回答气泡顶部加小字灰色提示：「当前为离线摘要版，若需要更精准回答请联系管理员开通 LLM」。

#### 3.6.3 异常 UI
- 问答 15 秒未回：显示骨架 + 转圈 + "AI 思考中…（预计 15s）" + 取消按钮；超过 30s toast "网络可能较慢，后台仍在生成，稍后可在问答历史中查看"，后续从 history 轮询补回来。

**接口**：`POST /api/courses/{id}/qa/ask`、`GET /api/courses/{id}/qa/history`、`POST /api/qa/{qid}/feedback`。

### 3.7 学习路径推荐 `/courses/:courseId/path`（核心页面 3）

参考 §12.5 的 BFS recommend_learning_path 算法。

#### 3.7.1 页面分 3 区块
**Block A：目标设置面板**
- "我想掌握："（下拉，从所有知识点里选，默认"最近最薄弱节点"（掌握率最低 category 中 degree 最大节点））
- "从：已掌握节点出发"（只读：当前掌握集合自动带入）
- 高级：Limit 步数（默认 10 / 20 / 30）
- 按钮：「重新生成路径」

**Block B：G6 可视化路径子图**（§13.5 `GET /api/courses/{id}/learning-path/visualize` 返回的子图）
- 节点按 4 色渲染：
  - ✅ 已掌握：绿色 fill，白底 ✓
  - 🎯 推荐中：黄色边框 + 脉冲动画
  - ⭐ 目标节点：蓝色发光
  - ⛔ 其余未掌握（非推荐）：灰度
- 边颜色："前置知识"用虚线箭头，其他关系为灰色。

**Block C：步骤卡片列表**
每张卡片包含：
1. 序号圈：① / ② / ③ ...
2. 标题：知识点名称 + 类型 Badge
3. 理由：后端返回 `reason` 字段（例如"先修已全部掌握，可以进入本知识点学习。"）
4. 前置清单：1-3 个 chip；已掌握 chip = 灰底 ✓；未掌握 chip = 黄底 !
5. CTA：「查看详情 → 图谱」/ `[✓] 我已掌握` 复选框（勾选 → POST progress → 卡片变绿 + 重新生成下一步推荐）。
6. 展开折叠：默认收起描述，点击 ▼ 显示 100 字简介。

**接口**：`POST /api/courses/{id}/learning-path/recommend`（Block A/B/C 数据源头）、`GET /api/courses/{id}/learning-path/{uid}/progress`（已掌握）、`POST /api/courses/{id}/learning-path/progress`（勾选我已掌握）、`GET .../visualize`（Block B 子图）。

### 3.8 我的进度 `/courses/:courseId/progress`
三卡片：
1. **掌握总览环**：中心显示「14/26（53.8%）」，外环有动画。
2. **按类型掌握条形图**：x 掌握率，y 节点类型（概念 / 定理 / 公式 / 算法 / 实例 / 其他）。
3. **学习热力日历**（最近 12 周）：颜色深浅 = 当日掌握节点数。hover → tooltip "8 月 26 日：掌握 3 个知识点（TCP 协议、…）"。
下方：最近掌握时间线（垂直时间轴图标），每个时间点显示节点名 + 类型。

**接口**：`GET /api/courses/{id}/learning-path/{uid}/progress`。

### 3.9 个人资料 `/profile`
头像 / 昵称 / 邮箱（只读） / 修改密码 / 退出登录 / 设备列表（选做）。

**接口**：`GET /api/users/{uid}/profile`、`PUT /api/users/{uid}/profile`、`POST /api/auth/logout`（自定义：清 token 即可）。

## 6. 核心体验 1：图谱探索 + 学习进度叠加

### 6.1 掌握状态实时回写 G6 Canvas
每次 `POST /learning-path/progress` 返回新的 `ProgressOut` 后，Pinia `graphStore.progressMap` 更新 → 调用 `graph.updateItem(id, { style, labelCfg })` 把节点重绘成"绿边/透明度"，**不需要全量 re-render**。

### 6.2 图谱性能策略
- 节点 ≤ 500：普通 dagre/force 布局即可。≥ 500 节点：
  1. 先给所有没命中的节点降低 opacity=0.35，画布初始化后一次性写 G6 dataChange；
  2. 力导向动画 `animate: false`（避免卡顿）；
  3. 边默认不渲染标签，hover 才显示。
- **虚拟化滚动**（可选）：在 GraphExplorer 详情抽屉里的邻居列表，分页每次加载 50 条。

## 7. 核心体验 2：RAG 问答 — 引用节点可跳 + 来源定位

### 7.1 回答引用 Chip 的跳转行为
- 若用户**当前**在 GraphExplorer 页：chip click → 调 `graphStore.selectNode(id)` + `graph.focusItem(id)` + 同时在引用小图谱（QA 右栏）里 setSelected。
- 若不在（在 QAView 默认独立打开）：chip click → 新 Tab 跳到 `/courses/:id/graph?highlight=n123,n456&select=n123`，`onMounted` 读取 query 应用高亮。

### 7.2 回答流式（SSE，可选增强）
后续可把 `/qa/ask` 升级为 SSE：每推一个 token 就 append 到回答气泡末尾，**显著降低感知等待**。骨架展示时仍显示"预计 15s"的灰色占位块。

## 8. 核心体验 3：推荐路径可视化（§12.5 BFS 算法）

### 8.1 目标未掌握时的"前置依赖缺多少"提示
LearningPath 顶部：`从目前掌握情况看，到目标 XX 还差 5 个前置知识点。预计 2 小时可学完。` （5 = 推荐 steps.length - mastered_count；2h = 5 × 24min 默认估值 × 难度系数加权）。

### 8.2 推荐失败场景 fallback
- BFS 返回空（图谱还没有任何"前置知识"关系）：
  回退为"按难度升序 + 未掌握优先"的顺序列表，并在顶部黄色提示 "当前课程尚未建立『前置知识』关系，以下为教师默认顺序，若需要个性化路径请联系老师"。
- 目标本身已掌握：显示庆祝动画 + "恭喜已掌握目标！试试更难的 🚀" + 推荐同类型但难度更高的 3 个。

## 9. 异常 & 边界场景处理

| 场景 | 前端表现 | 后端配合 |
|---|---|---|

| 加入课程后图谱为空 | Home 页面显示"老师还未完成知识抽取，耐心等待～" + 教师邮箱联系提示 | |
| RAG 回答为空 / 非 JSON 解析失败 | 气泡显示 "AI 暂时抽风，请稍后重试" + 重试按钮 | 后端捕获异常返回 used_llm=false 的兜底 |
| 生成学习路径耗时 >500ms | 显示骨架屏 8~10 个占位步骤 | 正常流程；超时 5s toast + 重试 |
| 标记掌握后未刷新推荐 | UI 立即乐观更新绿边 → 背景 `learningPath.generate()`；失败回滚 | |
| 过滤器命中 0 节点 | G6 画布中央居中显示"没有命中，试试清除过滤器？"按钮 | |
| G6 渲染空数据（节点=0） | 插画风空状态 + 按钮 "联系老师完善知识图谱" | |

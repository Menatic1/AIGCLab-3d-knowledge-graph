# 高等数学（上册）精简版教材样例
## 前言
本书是面向理工科大一学生的《高等数学（上册）》精简教材，核心目标是帮助读者建立从"函数"到"微积分基本定理"的完整知识脉络。本书的先修课程是**初等数学**，重点包括：集合、函数概念、基本初等函数（幂函数、指数函数、对数函数、三角函数、反三角函数）、三角函数恒等式、数列求和等。

# 第一章 函数与极限

## 1.1 函数
**函数**是高等数学的基本研究对象。设 D 是一个非空数集，若存在一个对应法则 f，使得对 D 中每个元素 x，都有唯一确定的实数 y 与之对应，则称 f 为定义在 D 上的一个**函数**，记作 y=f(x)。D 称为**定义域**，函数值全体称为**值域**。

**基本初等函数**包含六类，它们是所有复杂函数的基石：
1. **常数函数** y=C
2. **幂函数** y=x^α（α 为常数）
3. **指数函数** y=a^x（a>0，a≠1）
4. **对数函数** y=log_a x（a>0，a≠1），它是指数函数的**反函数**
5. **三角函数**：正弦函数 sin x、余弦函数 cos x、正切函数 tan x、余切函数 cot x、正割函数 sec x、余割函数 csc x
6. **反三角函数**：反正弦函数 arcsin x、反余弦函数 arccos x、反正切函数 arctan x

由基本初等函数经过有限次的四则运算与复合步骤所构成，并且可用一个式子表达的函数，称为**初等函数**。**初等函数**是微积分主要研究的函数类别。

## 1.2 数列的极限
**数列**是定义在正整数集上的函数。设 {x_n} 为一数列，如果存在常数 a，对于任意给定的正数 ε（不论它多么小），总存在正整数 N，使得当 n>N 时，不等式 |x_n-a|<ε 成立，则称常数 a 是数列 {x_n} 的**极限**，或称数列 {x_n} 收敛于 a。

**数列极限**是学习**函数极限**的基础，它的直观含义是"当 n 无限增大时，x_n 无限接近 a"。

**数列极限**的若干性质：唯一性、有界性、保号性。数列收敛必有界，但有界数列未必收敛（例如 {(-1)^n}）。

**数列收敛**的两个重要准则：
- **夹逼准则**：若 y_n ≤ x_n ≤ z_n，且 lim y_n = lim z_n = a，则 lim x_n = a。**夹逼准则**是证明两个重要极限的关键工具。
- **单调有界准则**：单调有界数列必有极限。**单调有界准则**是证明**重要极限 e** 存在的依据。

## 1.3 函数的极限
**函数的极限**是数列极限的推广：描述当自变量 x 趋向于某个值 x₀（或趋向无穷）时，函数值 f(x) 的变化趋势。

**函数的极限**与数列极限一样，满足四则运算法则：和、差、积、商（分母不为 0）的极限等于极限的和、差、积、商。

**两个重要极限**是后续**导数**推导的基础：
1. lim_{x→0} sin x / x = 1 。 这个**重要极限**证明了**正弦函数 sin x** 在 0 处的**导数**恰好是 cos 0 = 1。
2. lim_{x→∞} (1 + 1/x)^x = e 。 这个**重要极限 e** 是**指数函数 e^x** 与**自然对数函数 ln x** 的基石。

## 1.4 无穷小与无穷大
若 lim f(x) = 0，则称 f(x) 为该极限过程下的**无穷小**。无穷小不是"很小的数"，而是"以 0 为极限的变量"。

绝对值无限增大的变量称为**无穷大**。**无穷大**与**无穷小**互为倒数关系（在同一极限过程中）。

无穷小的比较是后续**泰勒公式**与**洛必达法则**的理论基础。设 α、β 都是无穷小：
- 若 lim β/α = 0，称 β 是比 α 高阶的**无穷小**
- 若 lim β/α = ∞，称 β 是比 α 低阶的**无穷小**
- 若 lim β/α = c ≠ 0，称 β 与 α 是同阶**无穷小**
- 若 lim β/α = 1，称 β 与 α 是**等价无穷小**，记为 α ~ β

常用的**等价无穷小**（当 x→0 时）：sin x ~ x ，tan x ~ x ，arcsin x ~ x ，1-cos x ~ x²/2 ，e^x - 1 ~ x ，ln(1+x) ~ x 。**等价无穷小替换**是计算 0/0 型极限的利器，它的理论依据是**泰勒公式**的一阶近似。

## 1.5 函数的连续性
设函数 f(x) 在 x₀ 的某一邻域内有定义，若 lim_{x→x₀} f(x) = f(x₀)，则称 f(x) 在 x₀ 处**连续**。不连续的点称为**间断点**。

**连续函数**的和、差、积、商（分母不为 0）仍为**连续函数**；**连续函数**的复合函数仍为**连续函数**。一切**初等函数**在其定义域内都是**连续函数**。

闭区间上的**连续函数**具有三大重要性质：**最值定理**（必有最大值与最小值）、**有界性定理**、**介值定理**。**介值定理**的特例——**零点存在定理**是方程求根的理论基础。

# 第二章 导数与微分

## 2.1 导数的概念
设函数 y=f(x) 在 x₀ 的某个邻域内有定义，当自变量 x 在 x₀ 处取得增量 Δx 时，相应地函数取得增量 Δy=f(x₀+Δx)-f(x₀)；如果 Δy/Δx 当 Δx→0 时的极限存在，则称函数 y=f(x) 在 x₀ 处可导，并称这个极限为 y=f(x) 在 x₀ 处的**导数**，记作 f'(x₀) 或 dy/dx|_{x=x₀}。

**导数**的几何意义是**切线斜率**。**导数**的物理意义是**瞬时速度**。

**导数**的严格定义基于**函数的极限**，因此**函数的极限**是学习**导数**的先修知识；反过来，可导必连续，即**导数**的存在性强于**函数的连续性**。

## 2.2 基本初等函数的导数公式
利用**两个重要极限**，可以推导出下列**基本导数公式**：
- (C)' = 0
- (x^α)' = α x^{α-1}，**幂函数**求导
- (sin x)' = cos x，**正弦函数**求导
- (cos x)' = -sin x，**余弦函数**求导
- (tan x)' = sec²x，**正切函数**求导
- (a^x)' = a^x ln a；特别地 (e^x)' = e^x，**指数函数**求导
- (log_a x)' = 1/(x ln a)；特别地 (ln x)' = 1/x，**对数函数**求导
- (arcsin x)' = 1/√(1-x²)，**反正弦函数**求导
- (arctan x)' = 1/(1+x²)，**反正切函数**求导

上述**基本导数公式**是**初等函数**求导的基石，要求熟练记忆。

## 2.3 求导法则
**求导法则**包括：四则运算法则、反函数求导法则、复合函数求导的**链式法则**。

**链式法则**是复合函数求导的核心：若 y=f(u)，u=g(x) 都可导，则 dy/dx = f'(g(x))·g'(x)。**链式法则**是推导**隐函数求导**、**参数方程求导**以及**高阶导数**递推的关键。

## 2.4 高阶导数
若函数 f(x) 的**导数** f'(x) 仍然可导，则称 f'(x) 的**导数**为 f(x) 的二阶**导数**，记作 f''(x) 或 d²y/dx²。更高阶记为 f^{(n)}(x)。

二阶**导数**的物理意义是**加速度**；它的几何意义反映曲线的凹凸性。

**高阶导数**与**泰勒公式**密切相关：**泰勒公式**用 n 阶多项式在一点附近逼近函数，系数恰好由 f^{(k)}(x₀)/k! 给出。

## 2.5 微分
设 y=f(x) 在某区间内有定义，x₀ 及 x₀+Δx 在这区间内，如果函数增量 Δy=f(x₀+Δx)-f(x₀) 可表示为 Δy = A·Δx + o(Δx)（其中 A 是不依赖于 Δx 的常数），则称 y=f(x) 在 x₀ 点是可微的，而 A·Δx 叫做 y=f(x) 在点 x₀ 相应于自变量增量 Δx 的**微分**，记作 dy。

函数可微 ⟺ 函数可导，并且 dy = f'(x₀)·Δx。因此**微分**本质上是**导数**的线性主部，是**微分中值定理**研究的对象之一。

# 第三章 微分中值定理与导数的应用

## 3.1 罗尔定理
罗尔定理是三大**微分中值定理**的基础。
**罗尔定理**：如果函数 f(x) 满足：(1) 在闭区间 [a,b] 上**连续**；(2) 在开区间 (a,b) 内可导；(3) 在区间端点处的函数值相等，即 f(a)=f(b)；那么在 (a,b) 内至少存在一点 ξ，使得 f'(ξ)=0。

**罗尔定理**的证明基于**最值定理**和**费马引理**。

## 3.2 拉格朗日中值定理
**拉格朗日中值定理**：如果 f(x) 满足：(1) 在 [a,b] 上**连续**；(2) 在 (a,b) 内可导；则至少存在一点 ξ∈(a,b)，使得 f(b)-f(a) = f'(ξ)(b-a)。

**拉格朗日中值定理**是**罗尔定理**的推广，它去掉了 f(a)=f(b) 这个条件。当 f(a)=f(b) 时，**拉格朗日中值定理**就退化为**罗尔定理**，因此**拉格朗日中值定理**包含**罗尔定理**。

## 3.3 柯西中值定理
**柯西中值定理**是**拉格朗日中值定理**的进一步推广，针对两个函数。
设函数 f(x)、g(x) 满足：(1) 在 [a,b] 上**连续**；(2) 在 (a,b) 内可导；(3) 对任一 x∈(a,b)，g'(x)≠0；则至少存在一点 ξ∈(a,b)，使得 (f(b)-f(a))/(g(b)-g(a)) = f'(ξ)/g'(ξ)。

当 g(x)=x 时，**柯西中值定理**退化为**拉格朗日中值定理**；所以三大**微分中值定理**的关系是：罗尔定理 ⊂ 拉格朗日中值定理 ⊂ 柯西中值定理。

**柯西中值定理**最重要的应用之一是证明**洛必达法则**。

## 3.4 洛必达法则
**洛必达法则**是计算"0/0"型或"∞/∞"型不定式极限的利器。
**洛必达法则 (0/0 型)**：设 (1) lim f(x)=0，lim g(x)=0；(2) 在 x₀ 的某去心邻域内 f'(x) 与 g'(x) 都存在，且 g'(x)≠0；(3) lim f'(x)/g'(x) 存在（或为 ∞）；则 lim f(x)/g(x) = lim f'(x)/g'(x)。

**洛必达法则**的证明基于**柯西中值定理**，换言之，**柯西中值定理**是**洛必达法则**的直接先修知识。

**洛必达法则**可以连续多次使用，但每一步都必须验证仍然是 0/0 或 ∞/∞ 型。其他类型的不定式（0·∞，∞-∞，0^0，1^∞，∞^0）应先通过代数变形转化为 0/0 或 ∞/∞ 型，再使用**洛必达法则**。

## 3.5 函数的单调性与极值
设 f(x) 在 [a,b] 上**连续**，在 (a,b) 内可导：
- 若在 (a,b) 内 f'(x) > 0，则 f(x) 在 [a,b] 上单调增加
- 若在 (a,b) 内 f'(x) < 0，则 f(x) 在 [a,b] 上单调减少

**极值的必要条件**（费马引理）：若 f(x) 在 x₀ 可导，且在 x₀ 取得极值，则 f'(x₀)=0。使 f'(x)=0 的点称为**驻点**。

**极值的第一充分条件**用左右**导数**的符号变化判断极大/极小；**极值的第二充分条件**借助二阶**导数**的符号判断。

## 3.6 函数图形的描绘
函数的凹凸性由二阶**导数**判断：在区间 I 内，若 f''(x) > 0，则曲线是凹的（向下凸）；若 f''(x) < 0，则曲线是凸的（向上凸）。曲线凹向发生改变的点称为**拐点**。

结合**单调性**、**极值**、**凹凸性**、**拐点**、**渐近线**，即可完整描绘**初等函数**的图像。

# 第四章 不定积分
## 4.1 不定积分的概念与性质
在区间 I 上，可导函数 F(x) 的**导数**为 f(x)，即对任一 x∈I，都有 F'(x)=f(x)，那么函数 F(x) 就称为 f(x) 在区间 I 上的一个**原函数**。f(x) 的全体**原函数**称为 f(x) 的**不定积分**，记作 ∫f(x)dx。

求**不定积分**是求**导数**的逆运算。因此**基本导数公式**的每一条都对应一条**基本积分公式**。例如：
- ∫x^α dx = x^{α+1}/(α+1) + C（α≠-1），对应**幂函数**求导的逆
- ∫sin x dx = -cos x + C，对应**正弦函数**求导的逆
- ∫cos x dx = sin x + C
- ∫e^x dx = e^x + C，对应**指数函数**求导的逆
- ∫1/x dx = ln|x| + C，对应**自然对数函数**求导的逆
- ∫1/(1+x²) dx = arctan x + C，对应**反正切函数**求导的逆
- ∫1/√(1-x²) dx = arcsin x + C

**不定积分**的线性性质：∫[a f(x) + b g(x)] dx = a∫f(x)dx + b∫g(x)dx。

## 4.2 换元积分法
第一类**换元积分法**（凑微分）：令 u=φ(x)，则 ∫f(φ(x))φ'(x)dx = [∫f(u)du]_{u=φ(x)}。**换元积分法**本质上是**链式法则**的逆运算。

第二类**换元积分法**：令 x=φ(t)，则 ∫f(x)dx = ∫f(φ(t))φ'(t)dt。常用于去根号（三角代换、倒代换）。

## 4.3 分部积分法
**分部积分法**公式：∫u dv = uv - ∫v du。它来源于乘积的**导数**公式 (uv)' = u'v + uv'。
**分部积分法**特别适用于**指数函数**、**对数函数**、**反三角函数**与**幂函数**相乘的积分，口诀为"反对幂指三"——排在前面的优先作为 u。

# 第五章 定积分
## 5.1 定积分的概念
定积分的严格定义由黎曼和的极限给出：∫_a^b f(x)dx = lim_{λ→0} Σ f(ξ_i)Δx_i。这一定义是**曲边梯形面积**的数学抽象。

**定积分**的存在性定理：若 f(x) 在 [a,b] 上**连续**，则**定积分**存在，简称 f(x) 在 [a,b] 上可积。**定积分**的存在性依赖于**函数的连续性**，即**函数的连续性**是**定积分**存在的重要先修条件。

## 5.2 定积分的性质
**定积分**具有线性性质、区间可加性、保号性、估值性质。积分中值定理：若 f(x) 在 [a,b] 上**连续**，则至少存在一点 ξ∈[a,b]，使得 ∫_a^b f(x)dx = f(ξ)(b-a)。

## 5.3 微积分基本公式
牛顿-莱布尼茨公式（**微积分基本定理**）：如果 F(x) 是**连续函数** f(x) 在 [a,b] 上的一个**原函数**，则 ∫_a^b f(x)dx = F(b)-F(a)。

**微积分基本定理**是微积分学最核心的定理，它把看似无关的两个概念——**定积分**与**不定积分**——紧密联系起来；它告诉我们"求面积"的问题可以化归为求**原函数**，也就是求**导数**的逆。**微积分基本定理**是**定积分**与**不定积分**的桥梁。

## 5.4 反常积分
当积分区间无穷或被积函数在区间内有无穷间断点时，普通**定积分**不再适用，此时需要引入**反常积分**。
- 无穷限的**反常积分**：∫_a^{+∞} f(x)dx = lim_{b→+∞} ∫_a^b f(x)dx
- 无界函数的**反常积分**（瑕积分）：以瑕点为极限点定义

**反常积分**收敛性的判别常用**比较判别法**，与**无穷级数**的收敛判别法非常相似。

# 第六章 无穷级数
## 6.1 常数项级数
设 {u_n} 为一数列，表达式 Σ_{n=1}^{+∞} u_n 称为（常数项）**无穷级数**，简称**级数**。若**部分和数列** {S_n} 收敛于 S，则称**级数**收敛；否则发散。

**级数**的收敛性本质上就是**数列极限**的收敛性；因此**数列的极限**是**无穷级数**的先修知识。

**级数**收敛的必要条件：若 Σu_n 收敛，则 lim_{n→∞} u_n = 0。但逆命题不成立（调和级数 Σ1/n 发散）。

## 6.2 正项级数
各项非负的**级数**称为**正项级数**。**正项级数**收敛 ⟺ 其部分和数列有界。
常用的**正项级数**收敛判别法：
- **比较判别法**：大的收敛则小的收敛；小的发散则大的发散。**比较判别法**与**反常积分**的比较判别法可以类比学习。
- **比值判别法**（达朗贝尔）：lim u_{n+1}/u_n = ρ < 1 ⇒ 收敛，ρ>1 ⇒ 发散
- **根值判别法**（柯西）：lim (u_n)^{1/n} = ρ < 1 ⇒ 收敛

**p-级数** Σ1/n^p：当 p>1 时收敛；当 p≤1 时发散。它是**比较判别法**最常用的参照**级数**。

## 6.3 交错级数
正负项交替出现的**级数**称为**交错级数**。**莱布尼茨判别法**：若**交错级数** Σ(-1)^{n-1} u_n 满足 u_n 单调下降趋向 0，则它收敛，且余项的绝对值 ≤ u_{n+1}。

## 6.4 幂级数
形如 Σ a_n x^n 的**级数**称为**幂级数**，其中 a_n 称为系数。**幂级数**的收敛域通常是一个以 0 为中心的区间，其半径 R 可由**比值判别法**或**根值判别法**求得。

**幂级数**在其收敛区间内可以逐项求**导数**、逐项求积分，并且收敛半径保持不变。这一性质是函数展开为**泰勒级数**的理论基础。

## 6.5 函数展开成幂级数
如果 f(x) 在 x₀ 的某邻域内具有任意阶**导数**，则其**泰勒级数**为 Σ f^{(n)}(x₀)/n! · (x-x₀)^n。当该邻域内余项 R_n(x)→0 时，f(x) 与它的**泰勒级数**相等。特别地，x₀=0 时的**泰勒级数**称为**麦克劳林级数**。

常见的**麦克劳林级数**展开必须熟记：
- e^x = Σ x^n/n! （-∞<x<+∞），对应**指数函数**
- sin x = Σ (-1)^n x^{2n+1}/(2n+1)! ，对应**正弦函数**
- cos x = Σ (-1)^n x^{2n}/(2n)! ，对应**余弦函数**
- ln(1+x) = Σ (-1)^{n+1} x^n/n （|x|<1）
- 1/(1-x) = Σ x^n （|x|<1），它可视为**幂函数**/**等比数列求和**的推广。

**泰勒级数**是**泰勒公式**让 n→∞ 的推广；因此**泰勒公式**是学习**幂级数展开**的直接先修内容。

# 第七章 多元函数微分学
## 7.1 多元函数的基本概念
设 D 是平面上的一个非空点集，若对 D 中任一点 P(x,y)，按照一定的法则总有确定的 z 和它对应，则称 z 是 x,y 的**二元函数**，记为 z=f(x,y)。D 称为定义域。**二元函数**的几何意义是空间曲面。

**二元函数**的**极限**称为**二重极限**，它要求点 P(x,y) 以任意方式趋近于 P₀(x₀,y₀) 时函数值都趋向同一常数。**二重极限**比一元**函数的极限**更复杂，因为趋近路径可以是任意曲线。

若二重极限 lim_{(x,y)→(x₀,y₀)} f(x,y) = f(x₀,y₀)，则称 f(x,y) 在 (x₀,y₀) 处**连续**。一切多元**初等函数**在其定义域内都是**连续函数**。

## 7.2 偏导数
函数 z=f(x,y) 对 x 的**偏导数** f_x(x,y) 定义为固定 y 时，函数增量 Δ_x z 对 Δx 的**极限**。它的几何意义是曲面 y=y₀ 截线的**切线斜率**。同理可定义 f_y(x,y)。

**偏导数**本质上仍是一元**导数**的计算：只对当前变量按**基本导数公式**求导，其他变量视为常数。

## 7.3 全微分
如果函数 z=f(x,y) 在点 (x,y) 的全增量 Δz 可表示为 Δz = AΔx + BΔy + o(ρ)，其中 ρ=√(Δx²+Δy²)，则称 dz=AΔx+BΔy 为 f(x,y) 在该点的**全微分**。

多元函数的**全微分**对应一元函数的**微分**。可微的必要条件是两个**偏导数**都存在；可微的充分条件是两个**偏导数**在该点**连续**。

## 7.4 多元复合函数的求导法则
多元复合函数求导也满足**链式法则**：若 z=f(u,v)，u=φ(x,y)，v=ψ(x,y) 都可微，则
∂z/∂x = ∂z/∂u · ∂u/∂x + ∂z/∂v · ∂v/∂x
∂z/∂y = ∂z/∂u · ∂u/∂y + ∂z/∂v · ∂v/∂y

多元**链式法则**是一元**链式法则**在多个自变量情形下的推广。

## 7.5 多元函数的极值
设 f(x,y) 在 (x₀,y₀) 具有连续二阶**偏导数**，且 f_x=0, f_y=0（驻点），令 A=f_{xx}，B=f_{xy}，C=f_{yy}，Δ=AC-B²：
- Δ>0 且 A>0 时，f(x₀,y₀) 是极小值
- Δ>0 且 A<0 时，f(x₀,y₀) 是极大值
- Δ<0 时，(x₀,y₀) 是鞍点，不是极值
- Δ=0 时无法判定

实际应用中经常要求**条件极值**，即自变量还满足附加条件 φ(x,y)=0，此时使用**拉格朗日乘数法**：构造 L = f(x,y) + λφ(x,y)，解方程组 ∇L=0。

# 附录：知识脉络总览（供 AIGC 抽取验证）
为了帮助知识抽取系统正确识别关系，本节用自然语言再次列出各关键知识点的"先修/包含/对比"关系：
- **罗尔定理**是**拉格朗日中值定理**的特例，是学习**拉格朗日中值定理**的先修知识。
- **拉格朗日中值定理**是**柯西中值定理**的特例，是学习**柯西中值定理**的先修知识。
- **柯西中值定理**是证明**洛必达法则**的基础，是学习**洛必达法则**的直接先修。
- **数列的极限**是学习**函数的极限**的先修知识。
- **函数的极限**是学习**导数的概念**的先修知识。
- **导数的概念** + **高阶导数**是学习**微分中值定理**的先修知识。
- **导数的概念**与**不定积分**互为逆运算。
- **不定积分** + **函数的连续性**是学习**定积分**的先修知识。
- **微积分基本定理**把**不定积分**与**定积分**连接起来。
- **数列的极限**是学习**无穷级数**的先修知识。
- **无穷级数**中的**正项级数**与**反常积分**在收敛判别上高度相似，属于相关概念。
- **高阶导数**与**泰勒公式**相关，**泰勒公式**是学习**幂级数** / **泰勒级数**的先修知识。
- **多元函数的极限**是一元**函数的极限**的推广，二者是对比关系。
- 一元的**链式法则**是学习多元**链式法则**的先修知识。
- 一元的**微分**是学习多元**全微分**的先修知识。
- **初等函数**包含**基本初等函数**，**初等函数**包含**幂函数**、**指数函数**、**对数函数**、**三角函数**、**反三角函数**、**常数函数**。
- **两个重要极限**包含"重要极限 e"与"重要极限 sinx/x=1"，二者都属于**函数的极限**。
- **等价无穷小**是**无穷小的比较**的核心结论；**等价无穷小替换**与**洛必达法则**是计算 0/0 型极限的两种对比方法。
- **极值的第一充分条件**与**极值的第二充分条件**是判断一元函数极值的两种对比方法。
- **罗尔定理**、**拉格朗日中值定理**、**柯西中值定理**共同构成三大**微分中值定理**。
